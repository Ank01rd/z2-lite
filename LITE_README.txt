Z2 Mini Lite 1.5.0

Визуал повторяет стиль Z2 Mini без тяжёлых эффектов:
- тёмно-серый фон;
- компактные скруглённые карточки;
- левая боковая навигация;
- один слой поверхности без blur/live background;
- фильтры конфигов Все / ALT / Fake TLS / Simple / EXP / Base;
- раскрываемый список конфигов.

Окно: 920x640.

Настройки:
- светлая / тёмная тема;
- автозапуск Z2 Mini Lite с Windows;
- автозапуск Zapret через Z2-AutoStart;
- путь к папке Zapret.

После создания обычного Windows-проекта замените lib/ и pubspec.yaml.
